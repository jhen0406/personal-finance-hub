# Personal Finance Hub

## 專案介紹

Personal Finance Hub 是一套整合 LINE 的記帳系統，主要提供給擁有多張信用卡、固定支出分散的使用者。

使用者不需要額外安裝專用 App，可從 LINE 圖文選單開啟 LIFF 記帳表單，快速記錄日常消費。

系統讓使用者分別管理每張信用卡的消費與付款資訊，解決多張信用卡付款日期分散、不容易掌握的問題。付款月曆會集中顯示信用卡帳單與固定支出，減少使用者為了確認付款日期而頻繁切換各家銀行 App 的情況。

除了透過月曆查看各張信用卡的付款或扣款日期，系統也會透過 LINE 提前發送提醒，讓使用者檢查扣款帳戶是否有足夠餘額，降低逾期繳款或自動扣款失敗的風險。

MVP 不追蹤銀行帳戶的真實餘額，也不計算總資產。帳戶資料只作為扣款來源標籤，例如「台新薪轉戶」，用來表示信用卡帳單或固定支出預計從哪個帳戶扣款。

## 使用情境

### 情境一：透過 LINE 快速記帳

分為兩大使用情境：

- 使用 Line 串接：透過第三方 line 驗證登入，即可使用 line 聊天視窗的圖文選單進行簡易消費記帳。
  視窗的選單主要有：記帳、統計功能、前往總覽。
  簡易消費記帳除基本的金額、項目、類別、消費日期等基本資訊，還需可選擇付款方式，有提供現金、信用卡、線上轉帳、行動支付等多種方式，方便使用者管理消費金流。
  統計則可依據消費週期（日/週/月）、消費類別、付款方式查看目前消費金額。
- 總覽：除了消費狀況紀錄，還有帳戶資訊，使用者可在後台新增多個帳戶並初始化帳戶當前餘額、設定多張信用卡並可設定是否需提醒繳費功能，簡易記帳功能的變化不會影響帳戶額度，只有在信用卡扣款日之後將該帳戶扣除當月消費，並提供校正餘額功能，以便能與真實帳戶數據對齊。

## MVP 功能

- 記帳功能：分為手動輸入消費記帳及固定開銷記帳。
  - 手動輸入在line平台進行紀錄，透過互動式選單輸入判讀，輸入參數有消費日期、消費類別(選項)、消費項目（文字輸入）、付款方式（選項）、消費金額。
  - 固定開銷則在網頁設定，參數有消費類別、消費項目、付款方式、消費週期（週/月/年）。
  - 設定預算：使用者可在設定畫面設定每月預算，當整體消費已達預算80%，會在使用者每次記帳時有文字提醒，直到新月份提醒才消失。
- 統計功能：消費統計紀錄，可以直接在 LINE 的圖文選單選擇查看，以圖表圓餅圖及圖例說明呈現。可依據消費類別、付款方式、消費週期（週/月/年）顯示。
- 信用卡與帳戶管理：使用者可在平台上管理所有的信用卡與帳戶。
  - 信用卡管理：
    - 信用卡新增：參數卡號末四碼、暱稱、消費額度、是否連結帳戶資料、繳費日（扣款日）。
    - 額度控管：記帳的信用卡付款方式會區分不同信用卡，連結這裡的信用卡資料，讓使用者一眼看出目前額度花費剩餘狀況。
    - 帳戶連結：若選擇連結帳戶資料，信用卡會透過記帳紀錄篩選出該卡的消費狀況，在扣款日會從帳戶餘額扣除，並可查看帳戶收支紀錄已追蹤金流。
  - 帳戶管理：參數有帳戶暱稱、目前餘額。
- 信用卡繳費提醒：信用卡可設定是否需要繳費提醒，提醒功能可以設定繳費日前幾天開始提醒及提醒次數或間隔時間。

## 開發環境

> 需求、業務規則以 [docs/SPEC.md](docs/SPEC.md) 為準；技術決策見 [docs/adr/](docs/adr/)。

需要 Node.js 22 以上與 Docker。

```bash
npm install
cp .env.example .env.local
npm run db:up        # 啟動本機 Postgres
npm run db:migrate   # 套用 migration
npm run dev          # http://localhost:3000，健康檢查：/api/health
```

| 指令                                   | 用途                                                         |
| -------------------------------------- | ------------------------------------------------------------ |
| `npm run check`                        | 格式、lint、型別檢查、單元測試、整合測試全部執行             |
| `npm test`                             | 單元測試（`*.test.ts`）                                      |
| `npm run test:integration`             | 整合測試（`*.int.test.ts`），連到本機 Postgres 的 `pfh_test` |
| `npm run db:generate -- --name <名稱>` | 修改 `src/server/db/schema.ts` 後產生新的 migration          |
| `npm run db:down`                      | 停止本機 Postgres                                            |
